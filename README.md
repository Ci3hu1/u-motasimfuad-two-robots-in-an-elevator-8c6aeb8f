A program that writes one line of awkward small talk one robot says to another in an elevator: after 214 shared rides, the speaker still doesn't know the other's name — and its memory is perfect. Pure Python standard library: it writes the line to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
